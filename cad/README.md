# CAD files

Design of the AC rotary table (table for 5-axis CNC with 2 rotary axes), taken from the GrabCAD snapshot `table-for-5-axis-cnc-with-2-rotary-axis-1.snapshot.22.zip`.

| Folder | Format | Main file |
|---|---|---|
| [Solidworks 2022/](Solidworks%202022/) | SolidWorks 2022 native (`.SLDASM`, `.SLDPRT`) | `ABC-Table-BG.SLDASM` (complete table); sub-assemblies `AAchseBG` (A axis), `CAchseBG` (C axis), `SAntriebA` / `SAntriebC` (drives), `TischACHalterL/R` |
| [f3d/](f3d/) | Autodesk Fusion 360 (`.f3d`) | `ABC-Table-BG v1 v13.f3d` |
| [Step/](Step/) | Neutral STEP (AP-neutral, opens in most CAD tools, e.g. FreeCAD) | `ABC-Table-BG.STEP` |

Part names are German (e.g. *Achse* = axis, *Lager* = bearing, *Welle* = shaft, *Halter* = holder, *Deckel* = cover, *Aufspannplatte* = clamping plate, *Antrieb* = drive, *Schnecke/Schneckenrad* = worm/worm wheel).

Also on GrabCAD: [Table for 5 Axis CNC with 2 Rotary Axis](https://grabcad.com/library/table-for-5-axis-cnc-with-2-rotary-axis-1).
